# Austin Trujillo

Personal profile site for [austintrujillo.github.io](https://austintrujillo.github.io).

A single-page editorial showcase — skills, selected work, and contact — built with plain HTML, CSS, and a small bit of vanilla JS. No frameworks or build step.

## Local preview

Open `index.html` in a browser, or serve the directory:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Notes

- Contact email is intentionally blank until an inquiries address is added.
- LinkedIn URL is a placeholder (`#linkedin`) until confirmed.
